# SBI4U Curriculum Coverage Matrix

This matrix documents the Nexus Education SBI4U production course (Moodle course ID 33). It is based on *The Ontario Curriculum, Grades 11 and 12: Science, 2008 (revised)*. The 65 attached videos are user-authored Nexus source material. No third-party course content is represented as Nexus material.

## Coverage summary

- Overall expectations: A1-A2 and B1-B3 through F1-F3 covered.
- Specific expectations: all 69 expectations (A1.1-A1.13, A2.1-A2.2, and every B-F specific expectation) explicitly mapped.
- Learning resources: 7 Books, 51 chapters, 65 videos, 10 practice tasks with restricted reasoning guides, 5 investigations, and 31 additional assessment/reflection activities.
- Evaluation: Term Evaluation 70%; Final Evaluation 30%.
- Exact lesson-to-file paths are maintained in `scripts/sbi4u-course-plan.php` and checked by `scripts/verify-sbi4u-course.php` against Moodle File API hashes.
